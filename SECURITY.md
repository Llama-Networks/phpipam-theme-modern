# Security policy

This repository contains a client-side stylesheet and build scripts. It does
not include or manage a phpIPAM server.

Report a sensitive issue through GitHub's **Report a vulnerability** option if
it is available for this repository. Do not place credentials, private URLs,
or other sensitive deployment details in a public issue.

Security issues in phpIPAM itself should be reported to the
[phpIPAM project](https://github.com/phpipam/phpipam/security) rather than here.
